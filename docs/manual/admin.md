# はじめに

CrossShift（クロスシフト）は、結いの心の勤務表・職員情報・労働条件通知書・研修アンケートを、ひとつにまとめて管理するしくみです。このマニュアルでは、社長や事業所の管理者が使う画面の操作を説明します。

## このマニュアルの見かた

- 画面の写真は、練習用のデータ（架空の名前）で撮っています。
- 「🎬 操作動画」と書いてあるところは、同じ操作を動画（字幕・音声つき）でも見られます。動画のファイル名を目印にしてください。
- ボタンの名前は「　」で囲んで書いています。

## ログインする

🎬 動画：01\_ログインと画面の見方.mp4

1. ブラウザ（Chrome など）で CrossShift の画面を開きます。
2. 「ID（職員番号またはメール）」と「パスワード」を入れて、「ログイン」を押します。

![ログイン画面](images/admin-login.png)

> はじめてログインしたときは、パスワードの変更画面が出ます。新しいパスワード（8 文字以上）を 2 回入れて、「パスワードを変更する」を押してください。

## 画面の見かた

ログインすると、最初に「ダッシュボード」が開きます。

![ダッシュボード](images/admin-dashboard.png)

- **在籍**：いま在籍している職員の人数です。
- **年5日アラート**：有給を年 5 日取れていない人の数です。押すと一覧が開きます（「有給を確認する」の章）。
- **書類の期限**：資格証などの期限が切れた、または 30 日以内に切れる書類の数です。

左側がメニューです。

| メニュー       | できること                                                           |
| -------------- | -------------------------------------------------------------------- |
| 従業員         | 職員の登録・雇用契約・書類・研修記録・ログインの発行                 |
| 労働条件通知書 | 労働条件通知書の作成・発行・署名済みの登録                           |
| 研修アンケート | 研修アンケートの作成・配信・結果の確認                               |
| 勤務表         | 月ごとの勤務表づくり・職員への公開                                   |
| シフト希望     | 職員の希望休などの確認・代理入力                                     |
| 相談員チェック | 生活相談員の人数が配置基準に足りているかの確認                       |
| 有給管理       | 有給の残り日数・付与・年 5 日の取得状況                              |
| 設定           | 会社情報・労働条件通知書の設定・拠点・シフトパターン・自動作成の設定 |

使い終わったら、右上の「ログアウト」を押してください。共有のパソコンでは必ずログアウトしましょう。

# 勤務表を作る

🎬 動画：02\_勤務表を作って職員に公開する.mp4

勤務表は「自動で作った案を手直しして、職員に公開する」流れで作ります。

## 1. 拠点と月を選ぶ

1. メニューの「勤務表」を開きます。
2. 「拠点」と「対象月」を選んで、「表示」を押します。

![勤務表](images/admin-shifts.png)

縦に職員、横に日付が並びます。いちばん右の「公休」の列は、その人の公休の日数です。

> 「全拠点 (閲覧専用)」を選ぶと、すべての拠点の勤務表をまとめて見られます（見るだけで、直せません）。

## 2. 自動で案を作る

1. 右上の「シフト自動生成」を押します。
2. 確認が出たら「OK」を押します。

配置基準（設定 → 自動作成の設定）や、職員のシフト希望をもとに、1 か月分の案が入ります。自動で入れたマスには小さな「▾」が付きます。

> 自動生成をやり直すと、自動で入れたマスは作り直されます。手直しをする前にやり直すようにしてください。

## 3. 手直しする

1. 表の上の一覧から、勤務の記号（「日勤」「公休」など）を押して選びます。
2. 変えたいマスを押すと、その記号が入ります。続けて別のマスも押せます。
3. 終わったら「保存」を押します。

![勤務の記号の一覧](images/admin-shift-palette.png)

> **「保存」を押すまでは、変更は確定しません。** 保存しないまま別の画面に移ると、直した内容は消えます。
>
> 「全クリア」は確認なしで表を空にします（保存するまでは元に戻せます。「変更を破棄」を押してください）。

- 「前月コピー (空セルのみ)」：前の月と同じ日付の記号を、空いているマスにだけ写します。
- 「並べ替え」：表の職員の並び順を ▲▼ で変えて、「保存」します。
- 人が足りない日があると、表の下に「スタッフが足りない日があります」と、足りない時間帯が出ます。
- 職員の希望（希望休・有給・夜勤希望など）は、マスの色で表示されます。点線の枠は、まだ承認していない希望です。

## 4. 職員に公開する

1. 勤務表ができたら、右上の「職員に公開」を押します。
2. 確認が出たら「OK」を押します。

公開すると、職員が自分のスマホでその月のシフトを見られるようになります。公開した後に直した内容も、「保存」すればそのまま職員の画面に反映されます。公開をやめるときは「公開取消」を押します。

## 応援（ほかの事業所での勤務）

ほかの事業所に応援で入る職員は、「従業員」の編集画面の「応援で入る事業所（兼務先）」にチェックを入れておくと、応援先の勤務表にも行が出ます（応援先では見るだけで、直すのは所属している事業所の勤務表です）。

# シフト希望を確認する

🎬 動画：07\_シフト希望を確認する.mp4

![シフト希望](images/admin-shift-preferences.png)

## 職員から出された希望を承認する

1. メニューの「シフト希望」を開きます。
2. 「対象月」「拠点」「状態」で絞り込み、「絞り込み」を押します。
3. 一覧の「承認」または「却下」を押します。間違えたときは「戻す」で承認待ちに戻せます。

> 「承認」「却下」「削除」は確認なしですぐに反映されます。

## 紙で集めた希望休をまとめて入れる

1. 「希望休カレンダー入力」で「対象社員」を選び、「カレンダーを開く」を押します。
2. 「希望休」「有給」（ショートステイ・ナーシングホームの人は「夜勤希望」も）から種類を選びます。
3. カレンダーの日付を押します。もう一度押すと外れます。
4. 「保存」を押します。管理者が入れた希望は、承認済みになります。

## 勤務できない日を入れる

「単発の代理入力」で、職員・日付・種別を選んで「追加」を押します。**「勤務不可」は管理者だけが入力できます**（職員のスマホからは選べません）。

# 職員を登録する

🎬 動画：08\_従業員を登録してログインを発行する.mp4

## 新しい職員を登録する

1. メニューの「従業員」を開き、「＋ 新規登録」を押します。
2. 名前・フリガナ・所属拠点・職種・雇用形態などを入れて、「登録する」を押します。

![従業員の新規登録](images/admin-employee-new.png)

- **夜勤専従**：夜勤の希望を出した日だけ夜勤に入り、ほかの日は公休になります。
- **管理者（事務日・実績周り日を提出する）**：その職員がシフト希望で「事務日」「実績周り日」を出せるようになります。ログインの権限とは関係ありません。

## 職員の詳しい画面

一覧で名前を押すと、詳しい画面が開きます。上のタブで切り替えます。

| タブ       | 内容                                                       |
| ---------- | ---------------------------------------------------------- |
| 基本情報   | 名前・連絡先・所属・勤務条件・給与・ログイン               |
| 雇用契約   | 契約の履歴（労働条件通知書を発行すると自動で追加されます） |
| 書類       | 履歴書・資格証・署名済みの通知書などのファイル             |
| 研修       | 研修の記録（研修アンケートに答えると自動で追加されます）   |
| 制約・希望 | 月の勤務時間の上限、夜勤の上限、勤務できない曜日など       |

- 「休職にする (産休等)」：休職中の人は勤務表に出なくなります。
- 「退職処理」：退職日と理由を入れて「退職にする」を押します。データは消えず、「退職者一覧」に残ります。

> 「休職にする」「退職にする」「削除」などは、確認なしですぐに反映されます。押す前に、対象の職員をよく確認してください。

## スマホでログインできるようにする

1. 職員の詳しい画面の「ログイン（スマホ申請用）」で、「ログインを発行する」を押します。
2. 表示された「ID」と「初期パスワード」を本人に伝えます。**初期パスワードはこの一度しか表示されません。**

何人分もまとめて発行するときは、従業員の一覧の「ログイン発行」を使います。発行結果は「印刷する」で印刷して、本人に渡せます。

![ログイン発行](images/admin-credentials.png)

> パスワードを忘れた職員には、同じ場所の「パスワードを再発行する」で新しい初期パスワードを出してください。

# 労働条件通知書を作る

🎬 動画：03\_労働条件通知書を作る.mp4

5 つの項目（雇用形態・契約期間・勤務先・賃金・勤務時間）を入れると、労働条件通知書 2 枚と、雇用契約 同意書 兼 受領書 1 枚の、合わせて 3 枚（A4）ができます。

## 1. 作る

1. メニューの「労働条件通知書」を開き、「＋ 新しく作る」を押します。
2. 上から順に入れます。右側に、印刷される書面のプレビューが出ます。

![労働条件通知書の作成](images/admin-labor-notice-new.png)

| 項目       | 入れること                                                                              |
| ---------- | --------------------------------------------------------------------------------------- |
| 従業員     | 一覧から選ぶ（所属や仕事の内容が自動で入ります）                                        |
| 1 雇用形態 | 正社員・パート・夜勤専従。休日や賞与などの文言が自動で入ります                          |
| 2 契約期間 | 働き始める日。パートは最初の 6 か月が期間ありで、その後は期間の定めなしに切り替わります |
| 3 勤務先   | 事業所                                                                                  |
| 4 賃金     | 月給・時給・1 回あたりの金額（夜勤専従）、資格など                                      |
| 5 勤務時間 | 勤務パターン、週の日数・時間（正社員は 1 か月平均の時間）                               |

- 有給の日数（6 か月後）、社会保険・雇用保険に入るかどうかは自動で判定されます。
- 休日などの文言を一人だけ変えたいときは、「その他の項目（ふだんは変更不要）」を開いて直します。

## 2. 注意が出たとき

- **赤い枠**：書面に必ず書く項目が足りません。入れるまで発行できません。
- **黄色い枠**：最低賃金を下回る、社会保険の判定と違う、など。内容を確認し、「確認しました」にチェックを入れて、理由を書くと発行できます。

## 3. 発行して渡す

1. 「発行する」を押します。通知書番号（CH-2026-0001 など）が付き、その職員の雇用契約と給与なども同時に更新されます。
2. 「PDF をダウンロード（3枚）」を押して印刷し、本人に説明して渡します。
3. 本人が 3 枚目に署名したら、スマホで撮影するかスキャンして、「署名済みとして登録」から登録します。

![通知書の詳細](images/admin-labor-notice-detail.png)

> **発行した後は書き直せません。** 間違いに気づいたら「無効にする（作り直す）」を押し、「作り直す」から作り直してください（番号は欠番として残ります）。

## 契約の更新・無期への切り替え

一覧では、契約の終わりが 30 日以内の人が黄色くなり、「更新版を作成」（パートは「無期の通知書を作成」）のボタンが出ます。押すと前回の内容がコピーされ、開始日が前回の終わりの翌日になります。

# 研修アンケート

## アンケートを作って配る

🎬 動画：05\_研修アンケートを作って配る.mp4

1. メニューの「研修アンケート」を開き、「＋ 新しく作る」を押します。
2. 研修名・研修日・回答の期限を入れます。
3. 質問を作ります（下の表）。
4. 「配る相手」で事業所ごとの全員、または一人ずつ選びます。
5. 「保存する」を押します（まだ職員には見えません）。
6. 「配信する」を押すと、選んだ職員のマイページに届きます。

![研修アンケートの作成](images/admin-survey-new.png)

| 質問の種類                   | 使いかた                                                          |
| ---------------------------- | ----------------------------------------------------------------- |
| ひとつ選ぶ・いくつでも選ぶ   | 選択肢から選ぶ。「その他（自由記述）」も付けられます              |
| プルダウン                   | 選択肢が多いときに                                                |
| 数の評価                     | 1〜5、0〜10 などの数字で答える                                    |
| 表形式                       | いくつかの項目を同じ答え（よい・ふつう・よくない など）で評価する |
| 一行の答え・自由記述（長文） | 文章で答える                                                      |
| 日付                         | 日付を選ぶ                                                        |
| 見出し・説明                 | 「講師について」などの区切り。答える質問ではありません            |

- 質問の左の「⠿」をつかんで上下に動かすと、順番を入れ替えられます（スマホでも指で動かせます）。
- 質問と質問の間の「＋ ここに追加」で、好きな場所に質問を入れられます。「複製」で同じ質問をもう 1 つ作れます。
- よく使う質問がそろったら「この質問をひな形として保存」を押しておくと、次からは作成画面の上の「ひな形から作る」で選ぶだけで使えます。
- 回答した職員には、研修名と研修日で研修記録が自動で付きます。

> 回答が 1 件でも届いた後は、質問は変更できません（配る相手の追加はできます）。

## 結果を見る

🎬 動画：06\_研修アンケートの結果を見る.mp4

一覧で「結果を見る」を押すと、3 つの見かたで結果を確認できます。

![まとめ](images/admin-survey-result.png)

- **まとめ**：質問ごとの結果が縦に並びます。数の評価は平均点と人数の棒、選択肢は人数、表形式は項目ごとにいちばん多い答えが青くなります。自由記述は名前と一緒に並びます。
- **個別**：一人分の回答を 1 枚で見られます。左の名前か「次の人 →」で切り替えます。
- **未回答**：まだ答えていない人の一覧です。

![個別](images/admin-survey-people.png)

回答を締め切るときは「締め切る」を押します。「受付を再開する」で再開できます。

# 有給を確認する

🎬 動画：09\_有給を確認する.mp4

![有給管理](images/admin-leave.png)

- メニューの「有給管理」で、一人ずつの残りの日数と、次に付与される日が見られます。
- 付与の日が来た人がいると「自動付与を実行 (N 件)」のボタンに件数が出ます。押すと、法律どおりの日数がまとめて付与されます。
- 「詳細」で付与と消化の履歴を見られます。入社時の調整などは「手動付与の追加」で付与します。

## 年 5 日の取得義務

「年5日取得アラート」では、10 日以上付与された人のうち、年 5 日を取れていない人が出ます。

| 表示   | 意味                            |
| ------ | ------------------------------- |
| 違反   | 期限を過ぎても 5 日取れていない |
| 要対応 | 期限まで 3 か月を切っている     |
| 監視   | 期限まで 3 か月以上ある         |

![年5日アラート](images/admin-leave-alerts.png)

# 設定

設定は、メニューの「設定」を押すと開きます。ふだんはあまり変えない項目です。

## 労働条件通知書の設定

🎬 動画：04\_労働条件通知書の設定を変える.mp4

通知書を作るときに最初から入る内容を変えられます。発行済みの通知書は変わりません。

![労働条件通知書の設定](images/admin-labor-notice-settings.png)

- **区分ごとの初期値・手当**：正社員・パート・夜勤専従ごとの、休日・試用期間・昇給・賞与・退職金などの文言、契約期間、最初に選ぶ勤務パターン、書面に載せる手当、資格手当の金額。変えたら「○○の設定を保存」を押します。「最初の状態に戻す」で元に戻せます。
- **勤務パターン**：書面に載る勤務時間と休憩。使わなくなったものは「使う」のチェックを外します。
- **最低賃金**：毎年 10 月ごろの改定のときに、新しい金額と発効日を「追加」してください。古い行は消さずに残します。

## 会社情報

法人名・所在地・代表者・賃金の締切日と支払日・割増賃金率・相談窓口など、通知書に印刷される会社共通の内容です。「労働条件通知書の判定に使う設定」では、従業員数（社会保険の判定）や、夜勤専従も変形労働時間制の労使協定の対象かどうかを設定します。

![会社情報](images/admin-company.png)

## 拠点

事業所の名前・住所・都道府県・管理者名・電話番号です。管理者名と電話番号は、労働条件通知書の相談窓口に印刷されます。

![拠点](images/admin-offices.png)

## シフトパターン・自動作成の設定

- **シフトパターン**：勤務表で使う記号（早・日勤・遅・夜入・夜明・公休 など）の名前・時間・色・並び順。
- **自動作成の設定**：連勤の上限、1 か月の夜勤回数の上限、パートの年収上限、曜日ごとの必要人数（午前・午後・相談員・看護師・夜勤）。ここで決めた人数が、勤務表の自動生成と「人が足りない日」の表示に使われます。

# 困ったときは

| こんなとき                 | どうする                                                                                 |
| -------------------------- | ---------------------------------------------------------------------------------------- |
| 職員がパスワードを忘れた   | 職員の詳しい画面の「パスワードを再発行する」で新しい初期パスワードを出して伝える         |
| 自分のパスワードを変えたい | 右上の名前を押し、「パスワード変更」で変える                                             |
| 勤務表の変更が消えた       | 「保存」を押さずに画面を移ると消えます。もう一度入れて「保存」してください               |
| 職員にシフトが見えない     | その月を「職員に公開」しているか確認してください（所属している事業所の月を公開します）   |
| 通知書を間違えて発行した   | 詳細の「無効にする（作り直す）」→「作り直す」                                            |
| アンケートの質問を直したい | 回答が届く前なら「編集」で直せます。届いた後は「複製して新しく作る」で作り直してください |
