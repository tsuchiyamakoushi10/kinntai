# はじめに

CrossShift（クロスシフト）は、自分のスマホでシフトを見たり、休みの希望を出したり、研修アンケートに答えたりできるしくみです。

- 画面の写真は練習用のデータ（架空の名前）で撮っています。
- 「🎬 操作動画」と書いてあるところは、同じ操作を動画（字幕・音声つき）でも見られます。

# はじめてのログイン

🎬 動画：11\_はじめてのログイン.mp4

1. 管理者から、**ID** と **初期パスワード** を受け取ります。
2. スマホのブラウザで CrossShift を開きます。
3. 「ID（職員番号またはメール）」と「パスワード」を入れて、「ログイン」を押します。
4. パスワードの変更画面が出たら、「現在のパスワード」（初期パスワード）と、「新しいパスワード」を 2 回入れて、「パスワードを変更する」を押します。新しいパスワードは **8 文字以上** にしてください。
5. 「変更後はこちらから続ける →」を押すと、ホームが開きます。

> ホームの画面をブラウザの「お気に入り」や「ホーム画面に追加」に登録しておくと、次から開くのが楽です。

# シフトを見る

🎬 動画：12\_シフトを見る・シフト希望を出す.mp4

1. ホームの「今月のシフトを見る」を押します。
2. 上に勤務の日数と公休の日数、下に毎日のシフトと時間が出ます。今日の行は黄色です。
3. 「←」「→」で前の月・次の月に切り替えます。

![シフト（スマホ）](images/staff-shifts.png)

> 「まだ公開されていません」と出る月は、管理者が勤務表を作っているところです。公開されるまでお待ちください。シフトを変えてほしいときは、管理者に連絡してください。

# シフト希望を出す

1. ホームの「シフト希望を出す」を押します。
2. 「対象月」を選んで「切替」を押します。
3. 「クリックで付ける種別」から「希望休」（または「有給」）を押して選びます。
4. 休みたい日を押します。もう一度押すと外れます。
5. 「保存」を押します。

![シフト希望（スマホ）](images/staff-preferences.png)

- 希望休は、**正社員は月 3 日、パートは月 5 日まで** です。多すぎると注意が出て保存できません。
- ショートステイ・ナーシングホームの人は「夜勤希望」も出せます。
- 希望は、管理者が確認してから確定します。下の「この月の提出状況」で、承認待ち・承認済・却下がわかります。
- 保存し直すと、その月の希望は全部入れ替わり、もう一度「承認待ち」になります。

> 勤務できない日がある場合は、管理者に伝えてください（スマホからは入れられません）。

# 研修アンケートに答える

🎬 動画：13\_研修アンケートに答える.mp4

1. ホームの黄色いお知らせ、または「研修アンケート」を押します。
2. 答えるアンケートを押します。
3. 上から順に答えます。「必須」と書いてある質問は必ず答えてください。
4. いちばん下の「送信する」を押します。

![アンケートの回答（スマホ）](images/staff-survey-answer.png)

- 数字の質問は、大きな数字のボタンを押します。
- 「いくつでも選ぶ」質問は、あてはまるものをすべて押します。「その他」を選ぶと、内容を書く欄が出ます。
- 表の形の質問は、項目ごとに 1 つずつ選びます。
- 締め切りまでなら、もう一度開いて答えを直せます。

# プロフィール・パスワード変更

ホームの「プロフィール・パスワード変更」で、電話番号とパスワードを変えられます。名前・所属・メールアドレスを変えたいときは、管理者に連絡してください。

![プロフィール（スマホ）](images/staff-profile.png)

# 困ったときは

| こんなとき             | どうする                                                                                                                                                   |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| パスワードを忘れた     | 管理者に伝えて、新しい初期パスワードを出してもらう（メールアドレスを登録している人は、ログイン画面の「パスワードをお忘れの方はこちら」からも変えられます） |
| ログインできない       | ID とパスワードをもう一度確認。それでもだめなら管理者へ                                                                                                    |
| シフトが見られない     | まだ公開されていない月です。公開されるまで待つ                                                                                                             |
| 希望を間違えて保存した | もう一度日付を押して直し、「保存」し直す                                                                                                                   |
